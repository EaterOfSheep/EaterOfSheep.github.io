Info

Scripted fight selection

N random drafts of the selected matchup are simulated. The draft with the lowest score is replayed. Formula weights and duration goals are configurable on the Settings tab.

Physics notes

Elastic ball collisions (mass ∝ radius²). Start speed 0; gradual thrust below speed 4 and drag above 8 (rage: thrust under 6, drag over 12). Projectile speeds and reloads are class stats. Melee weapons block bullets. Victory linger is 5s, then the fight stops — use Replay (same seed) or Fight (new match).

Rage mode

A fighter enters rage the first time HP drops below 30%, or after taking 4 hits in a row without dealing any damage during that streak (hits more than 5s apart start a new streak).
While raging: body and weapons take a red hue, attack rate doubles (half reload / faster melee spin-up), thrust applies under speed 6, and drag only above speed 12.

Settings

Rebalance targets the class furthest from 50% WR. Below 50% is buffed; above 50% is nerfed. If a class is buffed then nerfed (or vice versa), it is skipped for the next N passes. Stops after max passes — use Continue rebalancing for another batch. Skunk: win slow → more gas spread; win fast → less spread; lose fast → more HP; lose slow → less HP.

Script scoring algorithm

Lower score is better. Only settings for the selected algorithm are shown.

Classic formula

score = Whp×relWinnerHP×(5 + Wlead×X) + Wdur×durationPenalty + Wgap×maxHitGapSec + Wattr×avgRelTotalHP

relWinnerHP = winner remaining ÷ winner starting HP (0–1).
X = fraction of time the eventual winner led in total HP.
durationPenalty = max(0, t−maxDur) + max(0, minDur−t).
maxHitGapSec = longest gap between combat events.
avgRelTotalHP = average (total HP ÷ starting total HP).

Save Video uses a two-pass pipeline when audio is enabled: (1) real-time audio simulation, (2) same seeded fight encoded as video at a configurable wall-clock sim rate (optional; off by default), then ffmpeg speeds video to 1.0× and muxes with audio. Video-only skips pass 1. Frame-gap stutter detection + retries still apply.

When off, capture runs at 30 fps (faster encode, smaller files). Fight physics timestep stays the same; only capture rate changes.

If a capture pass has too many long frame gaps (CPU stall), the video pass is re-attempted up to this many times.

Gap detection defaults are stricter than before. A frame gap counts as “bad” if it exceeds max(min ms, expected frame time × multiplier). A pass is retried if bad-gap count hits the % or absolute threshold, or if any single gap exceeds the huge-stall limit. Lower multipliers / counts = stricter (more retries).

Off (default): video encodes at 1.0× real-time. On: video runs at the chosen fraction of real-time (more wall time per frame → fewer freezes); audio stays 1.0×; ffmpeg speeds video back to 1.0× before mux. 0.5 = half-speed capture; 0.2 = high-quality / slow.

Announcer uses @diffusionstudio/vits-web (VITS neural TTS in the browser). Audio is mixed into the Web Audio graph so it is included in saved videos. First use downloads a voice model (~tens of MB) into browser storage.

Serve over http://localhost or https (not file://). Needs network to load onnxruntime-web + VITS models, and storage (OPFS) to cache voices. If VITS fails, browser speechSynthesis is used live only (not mixed into videos).
